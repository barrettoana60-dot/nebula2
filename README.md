# Nebula Research

Plataforma de pesquisa acadêmica multimodal com interface Liquid Glass, análise inteligente de documentos, rede 3D de conexões entre pesquisadores e busca unificada via Semantic Scholar e CrossRef.

## Funcionalidades

- **Dashboard** — Métricas, sugestões de artigos, pesquisadores conectados
- **Pesquisa Inteligente** — Busca com análise de intenção, resultados locais + web
- **Repositório** — Upload e análise completa de PDFs, DOCX, CSV, imagens
- **Análise Avançada** — Gráficos estatísticos, mapa de origem, distribuição temporal
- **Conexões** — Rede 3D interativa de pesquisas relacionadas
- **Chat** — Mensagens entre pesquisadores com afinidade temática
- **Perfil** — Preferências aprendidas e histórico de buscas

## Stack

- HTML/CSS/JS vanilla (zero dependências de build)
- Plotly.js para gráficos e redes 3D
- PDF.js para extração de texto de PDFs
- JSZip para parsing de DOCX
- localStorage para persistência

## Deploy

Este projeto é 100% estático. Para deploy no Vercel:

1. Suba este repositório no GitHub
2. Acesse [vercel.com](https://vercel.com) e conecte seu GitHub
3. Selecione este repositório — o deploy é automático
